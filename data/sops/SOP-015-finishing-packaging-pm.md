# Purpose and scope

Weekly and monthly PM for M-41 Powder Coating Booth, M-42 Parts Washer and
M-51 Case Packer. Downtime booked to PM is planned downtime and should not
appear outside the scheduled window.

# Weekly PM: M-41 Powder Coating Booth

1. Replace or clean cartridge filters and record the differential pressure.
2. Blow down the booth and check the reclaim cyclone for build-up.
3. Verify gun kV output against the reference meter.
4. Check hook earthing. Strip hooks (HW-4004) on rotation - a coated hook does
   not earth, and poor earth is the leading cause of THIN_COAT.
5. Log the cure oven profile with a data logger and compare to the last run.

# Weekly PM: M-42 Parts Washer

1. Descale the spray nozzles and check the pattern on every manifold.
2. Clean the tank strainers and remove sludge.
3. Check pump seals and bearing temperature.
4. Calibrate the bath temperature probes against a reference thermometer.

# Weekly PM: M-51 Case Packer

1. Replace worn vacuum cups. Do not wait for a jam to tell you.
2. Check the vacuum level at the gripper with the pump running.
3. Clean the part-present and count sensors.
4. Inspect the label web path for burrs that catch and tear the web.

# Monthly, all three

- Full guard and interlock test. Never bypass an interlock; that is a
  stop-work issue.
- Lubricate conveyor chains and check tension.
- Review the last month's downtime by reason code with the line lead, and pick
  the single largest contributor to work on next.
